Maintained by Michael Wallis — Audio Programmer

Overview

Ableton Style GUI for JUCE is a collection of .cpp and .h files which provide the look and feel of Ableton GUI componets built upon the basic JUCE implementations of sliders and buttons. Currently only buttons and slider controls have been implemented but more elements will be added over time.

Information

The look and feel still follows the Ableton style and will be under the Ableton copyright. This is intended for personal use and to improve your own look and feel of JUCE style GUIs. This project was also build for this purpose and should not be used in any projects for release.
